# Japón 2026: guía de viaje

**🔗 Abrir la guía:** https://ximenaggamez-sys.github.io/japon-nippon-2026/

**🔗 Copia en este repositorio:** https://ximenaggamez-sys.github.io/Japonnippon/
(funciona cuando GitHub Pages está activado aquí: **Settings → Pages → Deploy from a branch → main → / (root) → Save**)

Guía bilingüe (español / inglés) para el viaje del 10 de noviembre al 4 de diciembre de 2026: mapa con todos los lugares por categoría, plan día por día, horarios, reservaciones, trenes, tips, gastos del grupo y clima. Funciona sin internet y se puede instalar en el celular.

## Instalarla en el celular

- **iPhone (Safari):** abre el link → botón Compartir → **Agregar a inicio**.
- **Android (Chrome):** abre el link → menú ⋮ → **Instalar app** o **Agregar a la pantalla principal**.

Ábrela una vez con internet para que se guarde todo; después funciona sin conexión.

## Qué hay en este repositorio

- `index.html`: la guía completa.
- `train.html`: la guía de trenes.
- `streets/` y `data/`: mapas de calles y estaciones para usar sin conexión.
- `sw.js` y `manifest.webmanifest`: lo que permite instalarla y usarla sin internet.

Lo que cada persona guarda en la guía (lugares, gastos, reservaciones) se queda solo en su celular; no se sube aquí.
